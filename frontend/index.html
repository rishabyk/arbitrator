Arbitrator — Edge ADS-B Telemetry Station 2026
San José / Bay Area

Live aircraft tracking station running on Raspberry Pi 5. Decodes Mode-S signals at 1090 MHz, streams telemetry via FastAPI, displays aircraft on a live map with trails, and fetches aircraft photos.

How It Works: Signal & Data Pipeline

STAGE 01 Antenna 1090 MHz antenna captures raw radio signals from nearby aircraft
→
STAGE 02 USB Tuner RTL-SDR v4 tuner digitizes radio waves at 2.4 million samples per second
→
STAGE 03 Decoder readsb decodes aircraft data, validates messages, and tracks positions
→
STAGE 04 Web Server FastAPI streams live aircraft positions and hardware health to this dashboard
