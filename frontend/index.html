Live flight tracking station running on Raspberry Pi 5. Decodes Mode-S signals at 1090 MHz, streams telemetry via FastAPI, displays flights on a live map with flight trails, and fetches aircraft photos.

Autonomous Marine Sensor Bus 2025

Sensor logging and backup power monitoring system for autonomous survey craft. Built for low-power edge computers with satellite connectivity.

How It Works: Signal & Data Pipeline

STAGE 01 Antenna 1090 MHz antenna captures raw radio signals from nearby aircraft
→
STAGE 02 USB Tuner RTL-SDR v4 tuner digitizes radio waves at 2.4 million samples per second
→
STAGE 03 Decoder readsb decodes flight data, validates messages, and tracks positions
→
STAGE 04 Web Server FastAPI streams live flight positions and hardware health to this dashboard
